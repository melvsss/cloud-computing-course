# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's cloud computing platform. It provides services for computing, storage, databases, networking, data analytics, containers, artificial intelligence, machine learning, security, and application development. Google Cloud uses Google's global infrastructure to help organizations build and scale applications.

## Global Infrastructure

Google Cloud operates a global infrastructure organized into geographic regions and zones, supported by Google's global network. Google Cloud provides regional and global services and allows organizations to deploy resources in locations selected for factors such as latency, availability, and data requirements.

Google Cloud's official locations page describes connectivity across **200+ countries and territories** and a global network with **10 million kilometers of terrestrial and subsea fiber**.

## Cloud Management Console

The **Google Cloud Console** is a web-based management interface for Google Cloud projects and resources. It allows users to create and manage resources, configure Identity and Access Management (IAM), manage billing, monitor infrastructure, and work with Google Cloud services through a graphical interface.

## Four (4) Core Services

1. **Compute Engine** – Provides configurable virtual machines for running applications and workloads.
2. **Cloud Storage** – Provides scalable object storage for application data, backups, media, and other files.
3. **BigQuery** – Provides a fully managed data warehouse and analytics platform for large datasets.
4. **Google Kubernetes Engine (GKE)** – Provides a managed Kubernetes environment for deploying and operating containerized applications.

## Three (3) Advantages

1. **Strong Data and AI Capabilities** – Google Cloud provides powerful analytics, machine learning, and AI services supported by Google's technology.
2. **Global Network** – Google's global infrastructure and network can support applications that require worldwide connectivity and low latency.
3. **Container and Open-Source Support** – Google Cloud has strong support for Kubernetes, containers, and open-source technologies.

## Typical Enterprise Use Cases

- Big data analytics and business intelligence
- Machine learning and artificial intelligence
- Containerized application deployment
- Website and application hosting
- Data storage and backup
- Global application delivery
- Data processing and real-time analytics
- Modernization of enterprise applications
