# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides cloud services for computing, storage, databases, networking, analytics, security, application development, artificial intelligence, and hybrid cloud environments. Azure enables organizations to build, deploy, manage, and scale applications using Microsoft's global cloud infrastructure.

## Global Infrastructure

Azure provides a global infrastructure made up of geographic regions, datacenters, availability and networking infrastructure, and specialized cloud locations. Microsoft's current global infrastructure page reports **80+ Azure regions and 500+ datacenters** worldwide.

Azure's geographic coverage helps organizations address requirements related to latency, data residency, regulatory compliance, availability, and disaster recovery.

## Cloud Management Console

The **Microsoft Azure Portal** is a unified web-based management console for Azure. It allows users to create, configure, monitor, and manage Azure resources such as virtual machines, storage, networks, and web applications. The portal also provides access control, billing information, monitoring, and Azure Cloud Shell.

## Four (4) Core Services

1. **Azure Virtual Machines** – Provides scalable virtual machines for running applications and workloads in the cloud.
2. **Azure Blob Storage** – Provides scalable object storage for unstructured data such as documents, media, backups, and application data.
3. **Azure SQL Database** – Provides a managed relational database service based on Microsoft SQL technologies.
4. **Azure Functions** – Provides serverless, event-driven compute for running code without managing traditional servers.

## Three (3) Advantages

1. **Strong Microsoft Integration** – Azure integrates well with Microsoft products and technologies such as Windows Server, Active Directory, Microsoft 365, and SQL Server.
2. **Global Infrastructure** – Azure provides a large worldwide infrastructure that supports low-latency and data-residency requirements.
3. **Hybrid Cloud Capabilities** – Azure provides tools and services for connecting on-premises environments with cloud resources.

## Typical Enterprise Use Cases

- Enterprise application hosting
- Windows Server and SQL Server workloads
- Hybrid cloud and on-premises integration
- Website and web application hosting
- Business intelligence and analytics
- Backup and disaster recovery
- Artificial intelligence and machine learning
- Enterprise identity and access management
