# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform operated by Amazon. It provides on-demand cloud services for computing, storage, databases, networking, security, analytics, and artificial intelligence. AWS allows organizations to build and operate applications without maintaining all of the physical hardware themselves.

## Global Infrastructure

AWS operates a global infrastructure organized into geographic Regions and Availability Zones. Each Region contains multiple Availability Zones that are designed to provide isolated infrastructure for better availability and reliability.

AWS also provides additional infrastructure such as Local Zones and edge locations. This global infrastructure allows organizations to deploy applications closer to their users.

## Cloud Management Console

The AWS Management Console is a web-based interface used to manage AWS services and resources. Users can create and configure services, monitor resources, manage security settings, and view billing information through the console.

## Four (4) Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that organizations can use to run applications and workloads in the cloud.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides scalable object storage for files, backups, documents, images, videos, and application data.

### 3. Amazon RDS

Amazon Relational Database Service (RDS) is a managed database service that makes it easier to set up, operate, and scale relational databases.

### 4. AWS Lambda

AWS Lambda is a serverless computing service that runs code in response to events without requiring users to manage servers.

## Three (3) Advantages

1. **Scalability** – AWS resources can be increased or decreased depending on workload requirements.
2. **Global Reach** – AWS has infrastructure in many geographic locations around the world.
3. **Wide Range of Services** – AWS provides many services for computing, storage, databases, networking, security, analytics, and artificial intelligence.

## Typical Enterprise Use Cases

AWS is commonly used by enterprises for:

- Hosting websites and web applications
- Running business applications
- Database hosting
- Data backup and disaster recovery
- Big data analytics
- Artificial intelligence and machine learning
- Serverless application development
- Content delivery
