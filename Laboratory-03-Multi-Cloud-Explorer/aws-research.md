# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform operated by Amazon. It provides a broad collection of on-demand services for computing, storage, databases, networking, security, analytics, and artificial intelligence. AWS allows organizations to build, deploy, and scale applications without having to maintain all of the underlying physical infrastructure.

## Global Infrastructure

AWS operates a global infrastructure organized into geographic **Regions** and multiple **Availability Zones (AZs)** within Regions. AWS also provides edge infrastructure such as CloudFront points of presence, Local Zones, and Wavelength Zones. According to AWS's current global infrastructure page, AWS spans **39 geographic Regions and 123 Availability Zones**.

This worldwide infrastructure helps organizations place workloads closer to users, improve availability, reduce latency, and support disaster recovery.

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to access and manage AWS services and resources. It provides access to service consoles, resource management, monitoring, account information, billing, and support. Users can select an AWS Region and manage services such as EC2, S3, RDS, and Lambda from the console.

## Four (4) Core Services

1. **Amazon EC2 (Elastic Compute Cloud)** – Provides resizable virtual server capacity for running applications and workloads.
2. **Amazon S3 (Simple Storage Service)** – Provides scalable object storage for files, backups, data lakes, and application data.
3. **Amazon RDS (Relational Database Service)** – Provides managed relational databases, reducing the need to perform database administration manually.
4. **AWS Lambda** – Provides serverless compute that runs code in response to events without requiring users to manage servers.

## Three (3) Advantages

1. **Scalability** – AWS resources can be increased or decreased according to workload requirements.
2. **Global Reach** – Its worldwide Regions and Availability Zones allow organizations to deploy applications closer to their customers.
3. **Large Service Portfolio** – AWS provides services for computing, storage, databases, networking, security, analytics, AI, and many other cloud needs.

## Typical Enterprise Use Cases

- Hosting websites and enterprise applications
- Data backup, archiving, and disaster recovery
- Running databases and business applications
- Data analytics and data warehousing
- Machine learning and generative AI applications
- Serverless application development
- Content delivery and globally distributed applications
