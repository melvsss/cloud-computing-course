
# Cloud Platform Recommendation Challenge

## Client A – Startup Company

**Recommended Cloud Platform: Amazon Web Services (AWS)**

AWS is a good choice for the startup because it provides many cloud services that can be used without purchasing expensive physical infrastructure. The startup can begin with a small amount of computing resources and scale them as the mobile application gains more users. AWS also offers serverless and pay-as-you-go services that can help control costs during the early stages of the business. Its large selection of services also provides flexibility as the company grows.

**Recommended Services:**
- Amazon EC2 – Virtual servers for application workloads
- Amazon S3 – Storage for application files and data
- AWS Lambda – Serverless application functions
- Amazon DynamoDB – Scalable NoSQL database

## Client B – University

**Recommended Cloud Platform: Microsoft Azure**

Microsoft Azure is the most appropriate choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making migration and identity management easier. The university can use Azure services while maintaining connections between its existing on-premises systems and cloud resources. This can help reduce migration complexity and support a hybrid cloud environment.

**Recommended Services:**
- Azure Virtual Machines – Running Windows Server workloads
- Microsoft Entra ID – Cloud identity and access management
- Azure Blob Storage – Storing documents and university data
- Azure Virtual Network – Connecting cloud resources securely

## Client C – AI Research Company

**Recommended Cloud Platform: Google Cloud Platform (GCP)**

Google Cloud Platform is a strong choice for the AI research company because Google has extensive expertise in artificial intelligence, machine learning, and high-performance computing. GCP provides specialized infrastructure and services that can support demanding AI and ML workloads. The company can use managed AI tools while also accessing powerful computing resources for training models. Google Cloud also provides strong support for data analytics and Kubernetes-based applications.

**Recommended Services:**
- Google Compute Engine – High-performance virtual machines for computing workloads
- Google Cloud TPU – Specialized hardware for machine learning workloads
- Vertex AI – Building, training, and deploying AI and ML models
- Google Kubernetes Engine (GKE) – Running containerized AI applications

## Client D – Global E-Commerce Company

**Recommended Cloud Platform: Amazon Web Services (AWS)**

AWS is an appropriate choice for the global e-commerce company because it provides a large global infrastructure and services designed for highly available and scalable applications. The company can deploy applications across multiple Availability Zones and Regions to improve reliability. AWS also provides automatic scaling and load balancing capabilities that can handle changes in customer traffic. These features are important for an e-commerce company that needs to remain available during normal traffic and sudden increases in demand.

**Recommended Services:**
- Amazon EC2 – Running e-commerce application servers
- Elastic Load Balancing – Distributing traffic across application servers
- Amazon EC2 Auto Scaling – Automatically adjusting computing capacity
- Amazon S3 – Storing product images, files, and other objects
- Amazon RDS – Managed relational database for application data
